# Community plugins

One file per plugin that lives in a repository of its own (docs/PUBLISHING.md, "Your own plugin"):

```yaml
# community/<id>.yaml
repo: https://github.com/someone/tessera-something
path: .
ref: v1.0.0
maintainer: someone
```

Not open yet: the index lists community plugins once Tessera's own plugins run on plugin API 1.0.
