# Photo clock

A face for the screensaver's photos: each photo of the folder you chose over the whole glass, and the time small in a
corner with the date under it, on a soft shade so it reads on a bright photo too.

It is an example to learn from: a screensaver whose one picture is the step's own photo, and that lets the screen move
it a little every minute, so the time never stands on the same pixels for hours.

## Set up

1. Add the plugin to a screen in Tessera. The screen builds once.
2. Open the screen's **Settings** and the **Screensaver** card. Turn on **Show in standby** (the screen needs **Auto
   standby** on too).
3. Click the **Photos** step, choose a folder of Home Assistant's media and how long each photo stands, and choose
   **Photo clock** under **Face**.
4. Choose the **Corner** the time stands in.

## Good to know

- It shows on screens that show pictures, as the photos step does. The CYD, the Waveshare 3.5-inch and the Hosyond
  4-inch show the clock instead.
- The photo fills the glass and is cut to it, whatever the step's own fill says.
- A screen without the plugin shows Tessera's own photos.
